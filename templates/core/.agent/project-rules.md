不要使用 AGENTS.override.md 隐藏共享入口，也不要为消除冲突强制覆盖未审阅内容。

1. 当前项目事实入口：待确认；指定背景、需求与决定的唯一当前来源，历史材料只作历史依据。

3. 每条说明用途与触发条件、准确入口、使用方式、环境与权限前提、不可用处理；版本或动态能力注明核实依据。未确认时保留 UNKNOWN，不声明虚构的可用能力。
4. 宿主与沙箱差异：仅填写已核实的路径或工具映射，不假设全局资源在所有环境可见；引用规则见 docs/agent/reference/resources.md。
