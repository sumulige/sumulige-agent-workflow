## 固定试点与成本记录

1. 只读分析：工作区前后 hash 相同，没有新增任务/记忆。
2. 小 Bug：复现、范围内修复、回归、相关文档更新，不强制三份规格。
3. 标准功能：批准的需求与验收、实现、证据和交接一致。
4. 中断接力：换客户端后根据同一 task、候选和 next 恢复，不依赖上一会话隐藏上下文。
5. 失败验收：命令失败、不可用、零测试和超时正确区分，任务不冒充完成。

每种客户端用相同合成夹具记录版本/模式、候选、输入、实际工具调用、文件差异、结果与证据链接。
另记耗时、可见 token/调用数、人工介入次数和返工次数；平台不提供的指标填 UNKNOWN。
成本比较需要相同任务与候选、多次执行和明确基线；本轮未调用模型，不报告节省比例。
