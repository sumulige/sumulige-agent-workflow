# 产品范围

目标：个人使用且可公开分发的 sumulige-coding-agent-workflow；统一文档维护、任务交接和验收证据。

批准依据：用户明确要求保留 sumulige-claude 不动、演进 sumulige-agent-workflow，并在方案后要求“帮我实施”。

1. 必需：三种文档组合、保守安装/升级、任务与 TODO、证据检查、七客户端薄入口。
2. 自动化：AI 随任务维护事实；确定性工具检查结构、漂移和引用，不以模型陈述代替执行结果。
3. 低成本：标准库与按需读取；不内置模型、后台服务或固定多 Agent 流程。不宣称未测量的成本降幅。
4. 非目标：合并 sumulige-claude、调度平台、模型路由、Skills 市场、改写客户端权限或共享私人记忆。
5. 边界：本地候选先完成；原生客户端、独立审查、全局安装、远端改名/发布分别验收与授权。

需求变更保留批准来源，不修改验收迁就实现。
